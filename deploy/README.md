# pidag Container Deployment

Isolated pidag + pi_agent_rust container for SDD orchestration on lnx.

## Quick Start

```bash
# 1. Deploy (sync source + build container)
./rsync-deploy.sh

# 2. Start the container
make up

# 3. Open web UI
open http://${DEPLOY_HOST_NAME}:4601
```

## Architecture

```
/podman/PROJECTS/pidag-container/     (on lnx)
├── Containerfile                     # Multi-stage build
├── podman-compose.yml                # Service definition
├── Makefile                          # Common operations
├── pidag/                            # rsync'd from crates/pidag
├── pi_agent_rust/                    # rsync'd from _upstream/pi_agent_rust
├── scripts/
│   ├── validate-exit-criteria.sh     # SDD validation
│   └── quality-gate.sh               # Rust quality checks
└── projects/                         # Persistent project storage
    └── <project-name>/
        ├── specs/
        │   └── 01-feature.md
        ├── .pidag/
        │   ├── config.toml
        │   └── pidag.redb
        └── src/
```

## Makefile Targets

| Target | Description |
|--------|-------------|
| `make deploy` | Sync source to lnx and build container |
| `make build` | Build container (after manual sync) |
| `make up` | Start the container |
| `make down` | Stop the container |
| `make logs` | View container logs |
| `make shell` | Open a shell in the container |
| `make run DAG=<path>` | Run a DAG file |
| `make sdd SPEC=<path>` | Generate SDD from spec |
| `make clean` | Remove container and image |

## Workflow: Spec to Implementation

```bash
# 1. Create a new project
podman exec pidag-runner mkdir -p /projects/my-app/{specs,.pidag,src}

# 2. Write a spec using pi
podman exec -it pidag-runner pi -p "write a spec for a REST API"
# Or manually create /projects/my-app/specs/01-api.md

# 3. Generate SDD DAG from spec
make sdd SPEC=/projects/my-app/specs/01-api.md

# 4. Run the DAG (implements the spec)
make run DAG=/projects/my-app/.pidag/temp_sdd.json

# 5. Monitor progress via web UI
open http://${DEPLOY_HOST_NAME}:4601
```

## Environment Variables

Set in `podman-compose.yml` or pass via environment:

| Variable | Description |
|----------|-------------|
| `NVIDIA_API_KEY` | NVIDIA API key for LLM calls |
| `ANTHROPIC_API_KEY` | Anthropic API key for Claude |
| `PIDAG_DEFAULT_MODEL` | Default model (default: nvidia/z-ai/glm-5.2) |
| `AGENT_MEMORY_URL` | agent-memory endpoint (default: host.containers.internal:7420) |

## Project Structure

Each project in `/projects/` follows this structure:

```
/projects/<project-name>/
├── specs/                  # Spec files (markdown)
│   ├── 01-feature-a.md
│   └── 02-feature-b.md
├── .pidag/
│   ├── config.toml         # pidag configuration
│   ├── pidag.redb            # Vault (runs, events, artifacts)
│   └── temp_sdd.json       # Generated SDD DAG
└── src/                    # Implementation (generated by SDD)
```

### Project config.toml

## Accessing agent-memory

The container is configured to reach agent-memory on the host via:

```
http://host.containers.internal:7420  (REST)
http://host.containers.internal:7421  (MCP)
```

Ensure agent-memory is running on lnx before starting pidag container.

## Troubleshooting

### Container won't start

```bash
# Check logs
make logs

# Verify ports aren't in use
ssh lnx "ss -tlnp | grep 4601"
```

### Can't reach agent-memory

```bash
# From inside container
podman exec pidag-runner curl http://host.containers.internal:7420/v1/memory/_topics
```

### Build fails

```bash
# Clean and rebuild
make clean
make deploy
```

### Rust compilation errors

The container builds pidag and pi from source. If compilation fails:

1. Verify source compiles locally first
2. Check Rust version compatibility (requires 1.88+)
3. Review build output: `ssh lnx "cd /podman/PROJECTS/pidag-container && podman-compose build --no-cache"`

## Updating

After making changes to pidag or pi_agent_rust:

```bash
# Redeploy (sync + rebuild)
./rsync-deploy.sh

# Or just rebuild (if source already synced)
make build

# Restart container
make down && make up
```
